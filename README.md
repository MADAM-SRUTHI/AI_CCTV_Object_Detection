# 🚨 AI CCTV Object Detection System

## 📌 Project Description

AI CCTV Object Detection System is a computer vision project that analyzes CCTV video using YOLO object detection and OpenCV.

The system detects objects from CCTV footage, displays bounding boxes with confidence scores, saves detection snapshots, and records detected objects in a log file.

A Streamlit dashboard is also provided to view the detection results.

## 🚀 Features

- 🎥 CCTV Video Processing
- 🤖 YOLO Object Detection
- 📦 Multiple Object Detection
- 🎯 Bounding Boxes with Confidence Scores
- 📸 Automatic Detection Snapshot
- 📝 Detection History Logging
- 📊 Streamlit Dashboard
- 🖥️ Real-time Detection Display

## 🛠️ Technologies Used

- Python
- YOLO
- Ultralytics
- OpenCV
- Streamlit
- Pandas
